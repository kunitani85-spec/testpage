# Uotora Recruit（株式会社魚寅 採用サイト WordPressテーマ）

デザイン・コーディング済みの採用サイトを、WordPress管理画面から更新できるようにしたオリジナルテーマです。プラグイン不要（Advanced Custom Fields等は使っていません）で、標準のWordPress機能だけで動きます。

## 導入方法

1. `wp-theme/uotora-recruit` フォルダを、お使いのWordPressの `wp-content/themes/` にコピーします。
2. WordPress管理画面 → 外観 → テーマ で「Uotora Recruit」を有効化します。
3. 設定 → 表示設定 で「ホームページの表示」を **固定ページ** ではなく、そのまま（テーマの `front-page.php` が自動でトップページになります）にしてください。
   ※ もし他のページビルダーの都合で固定ページを指定したい場合は、`front-page.php` の内容を該当ページのテンプレートとして扱うよう調整が必要です。

## 管理画面から編集できる項目

### 1. 社員インタビュー（管理画面メニュー「社員インタビュー」）
- 投稿タイトル＝社員名、アイキャッチ画像＝顔写真
- 「インタビュー情報」欄：役職バッジ・部署/役職・入社年・キャッチコピー・リード文
- 「Q&A（最大4問）」欄：質問と回答を入力（空欄の項目は表示されません）
- 「1日の流れ（最大6項目）」欄：時刻と内容を入力すると、詳細ページに「ある1日のスケジュール」として表示されます
- 表示順は投稿一覧の「並び替え」（クイック編集の「順序」）で調整できます

### 2. 募集職種（管理画面メニュー「募集職種」）
- 投稿タイトル＝職種名、本文（エディター）＝仕事内容の説明
- 「求人情報」欄：雇用形態（正社員 / パート等）

### 3. 福利厚生タブ（管理画面メニュー「福利厚生タブ」）
- 投稿タイトル＝タブの見出し、アイキャッチ画像＝タブ内の写真（未設定時はアイコン表示）
- 「タブ情報」欄：サブタイトル・チェックリスト（1行1項目）・アイコンの種類

### 4. カスタマイザー（外観 → カスタマイズ）
- 「ヒーロー（トップ大見出し）」：見出し文言・本文・写真2点
- 「会社紹介セクション」：見出し・本文・写真
- 「数字で見る会社」：統計4項目の数字・単位・ラベル
- 「会社情報（フッター）」：所在地・TEL・代表者・事業内容など
- 「エントリーフォーム」：問い合わせの送信先メールアドレス

### 5. メニュー（外観 → メニュー）
「主要ナビゲーション（ヘッダー）」の位置にメニューを割り当てると、ヘッダーのリンクを自由に編集できます。未設定の場合は既定のリンク（会社紹介・社員インタビュー・福利厚生・募集職種・エントリー）が自動的に表示されます。

## エントリーフォームについて
問い合わせフォームはプラグインを使わず、WordPress標準の `wp_mail()` で送信します。サーバーのメール送信設定（SMTP）によっては届かない場合があるため、本番運用時は "WP Mail SMTP" 等のメール到達性を高めるプラグインの併用をおすすめします。

## 遊び・演出について
- ヒーロー上部を小さな魚のアイコンがゆっくり泳ぎます（`prefers-reduced-motion` 設定時は非表示）
- ボタンはホバー・タップ時に水しぶきのような広がるエフェクトが出ます
- 社員インタビュー詳細ページの「1日の流れ」は、時刻の丸をホバーすると弾むように拡大します
- カード類のホバーには少しバウンドする動きを付けています

## 動作確認について
この納品にあたり、実際のWordPress環境（PHP・データベース）が用意できない開発環境で作業したため、PHPの構文チェックとコードレビューは行っていますが、実際のWordPress管理画面での動作確認は行えていません。導入後、以下の点をご確認ください。
- 各カスタム投稿タイプ（社員インタビュー／募集職種／福利厚生タブ）の新規追加・編集・保存
- カスタマイザーの各項目が実際にトップページへ反映されること
- エントリーフォームの送信テスト
- スマートフォン表示

不具合があれば、画面のスクリーンショットと合わせてご連絡いただければ修正します。
